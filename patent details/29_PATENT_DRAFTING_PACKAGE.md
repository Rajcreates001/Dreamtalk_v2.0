## A. INVENTION SUMMARY

**Title:** Neuromorphic Spiking Neural Network Brain with Multimodal Emotion Integration for Emotion-Aware Conversational Response Generation in Digital Twin Systems

**One-sentence summary:** A system and method that processes user input through five interconnected simulated brain areas using spiking neural network encoding and biologically-inspired learning rules, combined with multimodal emotion fusion, to generate emotion-modulated, action-varied conversational responses for digital twin systems.

---

## B. TECHNICAL PROBLEM

Conversational AI agents typically route user input directly to a large language model with a static system prompt, lacking:
1. Intermediate cognitive processing between input and response generation
2. Emotion-aware response modulation based on continuous emotional state
3. Varied response strategies based on neural competition
4. Learning from interaction outcomes

---

## C. SOLUTION

A neuromorphic brain architecture comprising:
1. Multi-strategy spike train encoding (rate, TTFS, phase, population)
2. Five interconnected simulated brain areas (PFC, dACC, Insula, IPL, Basal Ganglia)
3. Biologically-inspired learning rules (STDP, eligibility traces, TD learning)
4. Dynamic confidence-weighted multimodal emotion fusion
5. Brain-state-modulated LLM response generation
6. 12-type conversational action selection via basal ganglia competition

---

## D. ARCHITECTURE

```
Text Input → SNNEncoder → PFC → dACC → Basal Ganglia → LLM Response
                              ↑              ↑
Emotion Features → Insula ────┘              │
Voice + Text → Emotion Fusion ───────────────┘
                     ↑
            Voice Features + Text Features
```

---

## E. NOVELTY

The specific combination of:
- 5 brain areas with defined data flows for conversational AI
- Emotion fusion integrated INTO brain processing (not separate)
- Brain states (not just emotion labels) modulating LLM prompts
- 12-type action selection via basal ganglia competition
- STDP + eligibility trace + TD learning in one conversational system

---

## F. CLOSEST PRIOR ART

1. **BrainCog** — SNN framework with brain area abstractions; DreamTalk is a conversational application, not a framework
2. **Cognitive architectures (ACT-R, SOAR)** — Modular cognitive systems; DreamTalk uses SNN specifically
3. **Multimodal emotion fusion** — Many papers; DreamTalk's specific weighting may be different
4. **Basal ganglia computational models** — Frank (2005), Gurney (2001); DreamTalk applies to conversational action selection

---

## G. DIFFERENCES FROM PRIOR ART

1. **BrainCog** is a general-purpose SNN framework; DreamTalk is a specific conversational application with LLM integration
2. **Cognitive architectures** use symbolic/probabilistic modules; DreamTalk uses SNN spike trains
3. **Emotion fusion** papers focus on classification; DreamTalk integrates fusion INTO brain processing
4. **Basal ganglia models** are for motor control; DreamTalk applies to conversational response type selection
